# Ella's Butterfly Notes

A personal, photo-led field guide to five favourite butterfly species from Chitwan, Nepal.

## Project structure

```text
.
|-- index.html                  Page structure and content
|-- css/
|   `-- styles.css              Responsive visual design
|-- js/
|   |-- presentation.js         Species data and page interactions
|   `-- config/
|       `-- tailwind.config.js  Tailwind theme tokens
`-- assets/
    |-- butterflies/            Species photographs
    |-- backgrounds/            Chitwan slideshow photographs
    `-- video/                  Local hero media
```

## Run

Open `index.html` in a modern browser.

The Tailwind CDN, Google fonts, and the Instagram Reel stream require internet access. Photo credits and licence links are included in the page.
